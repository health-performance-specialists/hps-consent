Reusable WordPress consent management, Basic and Advanced Google Consent Mode v2, brand styling and GitHub release updates.

== Description ==
Self-hosted consent controls with a prominent Accept action, optional opt-out confirmation, granular choices, GPC support, page-specific consent bypasses, Elementor global colors and custom colors with opacity.

Starts disabled. Configure Settings > HPS Consent, remove duplicate GTM installations, configure consent requirements inside GTM and test before enabling. No automatic blocking of scripts outside GTM or central consent audit log is claimed. See README.md for complete setup and limitations.

== Installation ==
Upload hps-consent.zip from GitHub Releases through WordPress Plugins > Add Plugin > Upload Plugin. Activate, configure and enable in Settings > HPS Consent.
